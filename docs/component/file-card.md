# FileCard 文件卡片

> 状态：**规划中**（对齐 [`@ant-design/x` FileCard](https://x.ant.design/components/file-card-cn)）

用于展示单个文件信息（名称、类型、大小、预览等）。

## 何时使用

- 在对话附件、资料列表中展示文件摘要。

## 计划 API（对齐 React）

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| name | 文件名 | `string` | - |
| type | 文件类型 | `string` | - |
| size | 文件大小 | `number \| string` | - |
| src | 预览地址 | `string` | - |

组件实现后将补充完整示例与类型定义。
